## Scope and evidence labels

A scan of 327 tracked, non-test, non-generated `convex/**/*.ts` files at this candidate found 426 standard `export const X = mutation/action/httpAction(...)` registrations, matching Seat 1's stated scan. This recognizes those builder names, not arbitrary custom wrappers or dynamic registration. The named eleven-module inventory below is checked separately against each module's `mutation(...)` exports, with the two storage exports explicitly removed. These counts describe source, not live deployed functions. `scripts/pilotRouteMatrixCensus.test.ts` resolves named public-builder import aliases and compares direct exported registrations with this table, so missing, extra or duplicate rows fail. Custom/dynamic wrappers and other modules remain outside that check.

The normalized table below enumerates the public mutations in the eleven requested Unified Deal modules. It includes setup and cleanup operations so that money-bearing branches cannot disappear behind their names. `vehicles.generateUploadUrl` and `vehicles.deleteImage` are storage operations and are excluded from this money table. The subsequent route tables show argument branches and shared effects; they are not additional public registrations.

Supplier, expense, payroll, fixed-asset, prepaid, partner-equity and claims modules are outside this PR's classification assignment. Their separate lifecycle and correction policies need their own census and evidence under SCRUM-760. This is an evidence-scope exclusion, **not** an owner decision to exclude supplier work from launch: c23812 preserves G9/G10, fixed assets are OFF under ruling 4, and other modules are not authorized or certified by omission. Examples outside this table are `expenses.reverseExpense`, `prepaidExpenses.correctSchedule` and `supplierCostRecoveries.reverseReceipt`. `accountingCutover` is included here despite the earlier matrix's exclusion.

- ENABLED means the existing owner contract includes the specified route, subject to its guards and separate certification. It does not mean this PR measured all its combinations.
- EXCLUDED means outside the stated pilot contract or already retired. A refusal test is named where available; source inspection alone is not proof of a server block.
- OWNER DECISION NEEDED means the cited rulings do not decide the indicated branch. Existing code remains as it is. Neither activation nor containment is authorized by this label.
- INSPECTED means source and cited assertions were read. Only the commands in the execution section establish measured local passes. Every F3 addition is INSPECTED, not newly executed certification. Mounted component data, platform/OCC, production and authenticated EN/AR journeys remain UNAVAILABLE.

## Owner decisions needed

These are branch-specific questions. B continues to govern ordinary pre-completion operations. This PR adds no production guard and does not decide that another refund or correction is indispensable.

- `financeDealCosts.recordCustodyMovement`: ISSUED/RETURNED/consumption are in the oracle. REIMBURSED and REVERSAL, especially after finalization, extend beyond those literal rows. Owner must settle those branch boundaries; do not infer that all kinds are deferred.
